# Seus agentes

Coloque aqui os manifestos dos seus agentes (`python -m byte_agent novo-agente <id>` cria um modelo nesta pasta).
Os exemplos prontos (byte, bit, kronus) ficam dentro do pacote, em `byte_agent/agentes/`, e podem ser usados pelo
nome: `python -m byte_agent --agent kronus`. Um arquivo aqui com o mesmo id tem prioridade sobre o exemplo.
